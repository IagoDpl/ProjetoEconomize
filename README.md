# 💰 Projeto Economize

O **Economize** é uma aplicação web responsiva focada em finanças pessoais e controle de gastos. O objetivo principal do projeto é auxiliar os usuários na administração de suas despesas diárias, fornecendo uma interface limpa, intuitiva e direta para o monitoramento de saúde financeira.

---

## 🎨 Interface & UI/UX

O design foi desenvolvido seguindo princípios **minimalistas**, priorizando a usabilidade e a clareza visual. O objetivo foi remover distrações para que o usuário consiga registrar e visualizar suas finanças em poucos cliques.

*   Layout totalmente responsivo (adaptável para Mobile e Desktop).
*   Visualização clara de saldos, entradas e saídas.

---

## 🛠️ Tecnologias Utilizadas

A arquitetura do frontend foi construída focando em componentização, performance e manutenabilidade do código:

*   **[React](https://react.dev/):** Biblioteca principal utilizada para a construção de uma interface componentizada e reativa (Single Page Application).
*   **JavaScript (ES6+):** Lógica de manipulação de estados e controle de dados.
*   **CSS3:** Estilização customizada e responsiva utilizando variáveis CSS e layouts modernos (Flexbox/Grid), sem dependência de frameworks externos para garantir um bundle leve.

---

## 🚀 Como Executar o Projeto

Para clonar e rodar esta aplicação localmente, você precisará do [Git](https://git-scm.com) e do [Node.js](https://nodejs.org/) instalados em sua máquina.

### Passo a Passo

```bash
# 1. Clone este repositório
$ git clone [https://github.com/IagoDpl/ProjetoEconomize.git](https://github.com/IagoDpl/ProjetoEconomize.git)

# 2. Acesse a pasta do projeto
$ cd ProjetoEconomize

# 3. Instale as dependências
$ npm install

# 4. Inicie a aplicação em modo de desenvolvimento
$ npm start
